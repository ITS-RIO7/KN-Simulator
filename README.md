# KN Simulator

Empty Flutter scaffold: project structure, theme and the GitHub Actions APK
pipeline are ready. Screens and features are built from the spec.

## Run

```
flutter pub get
flutter run
```

The `android/` folder is generated by CI, so a fresh clone needs
`flutter create . --platforms=android` once for local builds.

## APK

Push to `main`, or run the *Build APK* workflow from the Actions tab. Pushing a
`v*` tag also publishes the APK to a GitHub Release.
